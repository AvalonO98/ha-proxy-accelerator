1 · 选择代理方式

同一时间只启用一种方式
ADocker 加速镜像
  • 改写 registry-mirrors，dockerd 热加载
  • 不重启、不中断 HA
  • 只对 Docker Hub 生效（ghcr.io 不受它影响）
B上游代理 / 订阅
  • 内置 mihomo，本地开 127.0.0.1:7890
  • dockerd 走代理，覆盖 ghcr.io 与 Docker Hub
  • 需要重启一次 dockerd（HA 短暂中断）
C内置 WireGuard 出口
  • 粘贴 .conf 即可，userspace 实现
  • 不改主机路由、不建 tun，风险小
  • 需要重启一次 dockerd（HA 短暂中断）
加速镜像地址在下面的「镜像源」区域填写（可自由增删自定义条目）。 改动只需要 SIGHUP 热加载，不会中断 HA。
订阅由内核自己拉取；如果订阅地址也被墙，可把订阅内容保存成 /share/netproxy/subscription.yaml， 内核会自动改用它作为本地订阅文件。

2 · 镜像源（Docker / GitHub 均可自定义）

两类都可以增删自定义条目，不限于内置的几个
地址需带 http(s)://；写入 dockerd 的 registry-mirrors，热加载生效。
前缀式：https://ghfast.top/ → https://ghfast.top/https://github.com/... ； 也支持含 {url} 的模板。插件下载内核、访问 GitHub 时按顺序尝试。
注意：dockerd 的 registry-mirrors 只对 Docker Hub 生效，ghcr.io 的镜像拉取请用方式 B（HTTP/SOCKS5 代理）。
